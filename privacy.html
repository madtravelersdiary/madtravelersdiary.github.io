Privacy Policy

Madtraveler Channel Manager is a personal tool used only by the owner of the YouTube channel "Madtraveler: Walking Germany 4K" to manage that channel.

What data it uses

With the owner's permission, the tool uses the YouTube API Services to read and update the owner's own channel: video details, playlists, thumbnails, publishing settings and channel statistics. It does not access any other user's data.

How the data is used and stored

The data is used only to manage the owner's own channel. It is kept on the owner's own device. It is not sold, shared with third parties, or used for advertising.

Google and YouTube

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See also the Google Privacy Policy. The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Data deletion

Data received from the YouTube API is refreshed or deleted within 30 days. The owner can delete all locally stored data at any time. Removing access (see below) stops all further use of the data.

Removing access

Access can be removed at any time in the Google account security settings: myaccount.google.com/permissions.
